# Agenda · Daily de ventas

```
DAILY VENTAS — [fecha]                 Duración: 15-30 min
Participantes: SDR, setter, closer, Santi, Mati
Lidera: [quién]

1. Apertura (1 min)
2. Ronda de updates (3 min por persona). Cada uno responde:
   · ¿Qué tenés para hacer hoy? (leads, llamadas, setteos)
   · ¿Cómo venís con las tareas de la semana?
   · ¿Algo te está trabando? ¿Necesitás ayuda?
3. Resolución de trabas (5-10 min). Lo rápido se resuelve acá.
   Lo complejo se agenda aparte solo con los involucrados.
4. Cierre (1 min) — prioridades del día
   (en ventana: a quién se llama primero — Grupo 2 con señales de compra)
```
