# Llamadas de venta B2B y B2C · scripts y banco de objeciones

Dos ofertas, dos llamadas distintas. La estructura es parecida; lo que cambia es el ADN.

| | B2B · Génesis | B2C · Mentoría |
| --- | --- | --- |
| Para quién | Dueño de e-commerce que ya vende (marca de consumibles 30M+/mes, o e-commerce en otro nicho con capital) y quiere escalar a +100M/mes con suscripción | El que recién arranca o quiere arrancar: todavía no largó, está testeando, o vende sin estabilidad |
| Precio | USD 5.000 (2 × 2.850 · 3 × 2.000) | USD 2.000 (2 × 1.100 · seña USD 200–400) |
| Tono | De igual a igual, lógico, técnico | Emocional: dolor hasta la capa identitaria + visión |
| Duración | ~1 hora | 45–50 min |
| Script | [`01-script-llamada-b2b-genesis.md`](01-script-llamada-b2b-genesis.md) | [`02-script-llamada-b2c-mentoria.md`](02-script-llamada-b2c-mentoria.md) |
